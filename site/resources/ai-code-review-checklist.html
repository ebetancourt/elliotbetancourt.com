The AI Code Review Checklist

6 areas to cover when AI writes most of the code

When AI writes 80% of the code, traditional code review misses what AI gets wrong. Hallucinated library references. Architectural assumptions the reviewer never approved. Tests that only verify what the AI already assumed. This checklist covers the six areas that matter most — each with a traffic-light scoring system so you know exactly where your review process stands.

6 AREAS

  1. Correctness — Edge cases that weren't in the prompt.
  2. Dependencies — Are all imports real and version-pinned?
  3. Security — Injection risks, secrets, license exposure.
  4. Test Coverage — Do tests verify behavior or just AI's assumptions?
  5. Architecture Fit — Does it fit your system, not the AI's context?
  6. Prompt Alignment — Intent vs. literal interpretation.

Each scored Green / Yellow / Red with criteria and the reason it matters.
