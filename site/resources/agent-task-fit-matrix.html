The Agent Task Fit Matrix

5 dimensions for deciding where AI agents belong — before you build

Most AI agent failures aren't model failures. They're deployment failures. Someone put an agent on a task it was never going to win. This one-pager gives you a structured way to evaluate any business process before you build an agent for it. Score across five dimensions. Know before you build.

THE 5 DIMENSIONS

  1. Trigger Clarity — Does the agent know unambiguously when to start?
  2. Output Verifiability — Can you check if it succeeded without re-running it?
  3. Error Cost — What happens when it's wrong?
  4. Tool Surface — How many APIs does it need to touch?
  5. Iteration Speed — How fast can you detect and correct failures?

Score each 1–5. Know before you build.
