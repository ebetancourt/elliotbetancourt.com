Agent Performance Review

A one-page framework for evaluating your AI agents

Most teams deploy AI agents without ever evaluating them. This template gives you 10 categories to score any agent — from reliability to true cost of ownership. Rate each 1-5, run it quarterly, and know exactly which agents to expand, retrain, or retire.

10 EVALUATION CATEGORIES

  1. Identity & Role — Name, function, domain, owner
  2. Reliability — Uptime, error rate, recovery time
  3. Output Quality — Accuracy, consistency, override rate
  4. Efficiency — Cost per task, tokens, completion time
  5. Autonomy Level — Autonomous / supervised / manual
  6. Risk Profile — Failure impact and blast radius
  7. Collaboration — Handoff quality to humans and agents
  8. Growth Trajectory — Is it improving over time?
  9. True Cost of Ownership — Infrastructure + API + oversight
  10. Recommendation — Continue / Expand / Retrain / Replace / Retire

Plus a scoring guide to make the call.
