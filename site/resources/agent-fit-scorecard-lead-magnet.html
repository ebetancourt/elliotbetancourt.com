The Agent FIT Scorecard

Is this process actually a good candidate for an AI agent?

Coding agents work because software engineering is a best-case scenario — not because agents are ready for everything else. I turned the reasoning behind why into six fit criteria. Score any candidate process before you greenlight the project, not after.

THE SIX DIMENSIONS

  1. Tool Surface — How many tools does it need?
  2. Medium — Plain text, or something messier?
  3. Correctness Signal — Does it tell you when it's wrong?
  4. Prior Art — How much precedent exists?
  5. Process Structure — Is there already a defined pattern?
  6. Judgment Requirement — Does success need taste or empathy?

Score each 1–5. Add them up. Know exactly where you stand.
